# Qt 在线升级

客户端和服务端 GUI 启动后异步检查一次更新（登录界面即可提示），不依赖业务登录。
断网、超时、无匹配平台或更新描述无效时静默继续启动。
headless 服务及命令行测试不检查。

- **稍后再说 / 关闭弹窗**：本次启动忽略，下次启动再次提示。
- **跳过此版本**：记住该版本号，更高版本仍会提示。清除对应应用 QSettings 的 `updates/client/skippedVersion` 或 `updates/server/skippedVersion` 可恢复。
- **下载更新**：显示可取消的下载进度，SHA-256 校验成功才保存正式文件；失败和取消不保留半包。完成后选择打开安装包或稍后安装。

## 配置地址

默认地址已内置到代码，无需另外配置：

- 客户端：`http://47.92.226.92:99/update/client.json`
- 服务端：`http://47.92.226.92:99/update/server.json`

需要覆盖默认值时，复制 `common/update-config.example.json` 为可执行文件同目录的 `update-config.json`，填写两个 manifest 地址。macOS app 内的位置为 `Contents/MacOS/update-config.json`，应在签名前打包。也可通过环境变量 `BOER_CLIENT_UPDATE_URL`、`BOER_SERVER_UPDATE_URL` 覆盖。无需修改代码。两个 manifest 可使用独立 URL。

当前两个 CMake 工程版本为 `2.1.11`；发布时修改各自 CMakeLists.txt 的 `project(... VERSION ...)`，编译时自动写入应用版本。版本格式为 2～4 段数字，按数值比较（1.10 高于 1.9）。

## 发布接口

HTTP/HTTPS GET 返回 JSON（最大 1 MiB），例如客户端：

```json
{
  "product": "client",
  "releases": {
    "windows-x86_64": {
      "version": "0.2.0",
      "notes": "1. 新增功能\n2. 修复问题",
      "url": "http://47.92.226.92:99/update/boer-client-0.2.0-setup.exe",
      "sha256": "替换为安装包实际的64位十六进制SHA256"
    }
  }
}
```

服务端使用 `"product": "server"`。平台键支持 `windows-x86_64`、`windows-arm64`、`macos-x86_64`、`macos-arm64`、`linux-x86_64`、`linux-arm64`，值取决于 Qt 的 currentCpuArchitecture。每个平台都单独提供完整安装包、版本号、更新内容和哈希。macOS universal 包可给两个平台键指向同一包。

Windows 支持 exe/msi，macOS 支持 dmg/pkg，Linux 支持 deb/rpm。必须为完整安装程序，不能直接发布裸 exe 或 zip。先上传包再更新 manifest。哈希可用 `shasum -a 256 <安装包>` 生成。HTTP 仅允许 `47.92.226.92:99/update/` 目录，其他服务器需使用 HTTPS。HTTP 无法防止更新说明和哈希同时被篡改；后续可升级为 HTTPS。HTTPS 使用系统信任的证书，不忽略 SSL 错误。

下载到应用本地数据目录的 `updates` 子目录。程序调用系统打开安装包，由安装程序完成替换；不会直接覆盖正在运行的文件，也Windows 打开安装包成功后自动退出当前应用，由正常析构关闭服务。服务端安装前需保存工作、安排停机并备份数据库。安装包须自行处理进程占用、保留业务数据/设置、系统权限与平台签名。本模块不实现安装器、差分更新或自动回滚。

## 验证

两端 CTest 的 `online_update` 覆盖数字版本比较、防降级、非法版本、默认地址、HTTP 目录限制、HTTPS、哈希与更新说明校验。正式发布前使用实际更新地址及平台安装器验收：启动提示、稍后重启、跳过后重启、更高版本提示、取消下载、断网、哈希错误和正常安装。

0.1.4 起，更新提示、下载进度与安装确认的固定 UI 文案跟随软件当前语言，不依赖操作系统的 Qt 默认翻译。下载面板默认 640×300，可根据小屏可用区域缩小，固定居中且跟随主窗口位置。提供未知大小的等待状态、下载百分比和 MB 信息。

0.1.5：更新提示→下载→校验结果→安装确认严格顺序切换，每一步先销毁上一窗口再继续；重复检查不产生第二条更新流程。成功、取消、哈希错误及中英文均有流程回归测试。安装器改为单窗口分页，语言选择在向导内完成，没有独立可拖动的语言窗口和系统标题栏。

0.1.6 更正：只有 Qt 程序本身移除顶部独立白色标题栏。NSIS 安装器、卸载器恢复标准标题栏、系统窗口按钮、语言选择弹窗和普通安装向导；不套用程序内弹窗的无边框/位置锁定规则。软件内更新各步骤仍固定居中并顺序关闭。
