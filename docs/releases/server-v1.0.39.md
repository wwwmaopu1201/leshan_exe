# Go + Vue 服务端 v1.0.39

- 修复客户现场多台设备经网关共用同一 IP 时，未上报主板号的设备按 IP 建立临时记录（PENDING-IP），其他设备重连后被误绑到同一条记录，导致设备名称/主板号来回变化（如 B3 分组 0504031 与 0504024 交替显示）、主板号显示为空、产量串机的问题。
- 设备未上报主板号前不再写入数据库：设备信息暂存在连接中，收到主板号后按主板号建立或匹配记录；生产数据在主板号到达前回复未接收，由设备重传，不丢数据。
- 去掉按 IP 匹配临时记录的逻辑，每条设备记录只对应一个主板号。

验证：Go 完整测试通过；新增同 IP 多设备（含无主板号设备）回归测试。

仅服务端升级至 1.0.39，使用 GitHub Actions 生成 Windows 标准版安装包（本次不打 Win7 版）。
