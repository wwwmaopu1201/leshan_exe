# Go + Vue 服务端 v1.0.40

- 修复客户现场多台设备经网关共用同一 IP 时，下发花型查找设备连接会退回按 IP 匹配，可能把花型下发到同 IP 下另一台在线设备的问题。现在只按主板号、设备记录和设备编号匹配，找不到则提示设备未连接。
- 按设备编号匹配设备记录时校验主板号，不再接管其他主板的记录；设备编号已被其他设备使用时，新记录改用主板号作为编号，避免两台设备共用同一连接标识。

说明：v1.0.39 起不再创建 IP 占位（PENDING-IP）记录。现场遗留的占位设备删除后不会再生成；服务端重启时也会自动清理同 IP 下已有正常设备的占位记录。

验证：Go 完整测试通过；新增同 IP 下发花型不串机、同设备编号不同主板不互相接管回归测试。

仅服务端升级至 1.0.40，使用 GitHub Actions 生成 Windows 标准版安装包（本次不打 Win7 版）。
