# Go 服务端 v1.0.35

- SQLite 主库统一写入排队，生产优先，同时公平处理设备更新、运行会话和后台同步。
- 生产记录及工资事务提交后才回复设备成功；失败按协议回复失败，重传按来源去重。
- 合并重复运行状态，减少高频保活写入；锁冲突有限重试，普通设备更新超过处理预算明确返回繁忙。
- 调试日志降低写入优先级，避免阻塞生产记录。

验证：Go 相关单元测试及写队列 race 检查通过；本机 SQLite 模拟 128 台设备，开启调试日志，共 6400 条生产和 640 次重传，无丢失、重复计件或普通更新错误。外部持锁六秒后恢复；持续占锁时约十秒返回 503。尚不代表 Windows 现场长期运行验证。

Windows 标准版、Windows 7 版均通过现有 GitHub Actions 手动打包。版本号在后端、npm、Cargo 和 Tauri 配置中统一为 1.0.35。
