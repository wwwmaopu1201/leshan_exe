# Go + Vue v1.0.37

- 修复数据库写入积压时，设备列表、设备树和其他查询接口一起等待、超时的问题。
- 查询连接与写入连接分开，写入事务在获取连接前排队，生产数据优先。
- 设备树和分组读取跳过无用的数据库更新。
- 历史补算保存进度，减少重复写入，支持取消并限制单次事务时间。
- 调试日志后台批量保存，繁忙时优先保证业务数据处理。

验证：Go 完整测试、关键并发竞态检查通过；128 条生产记录分别重复上传后，生产记录与工资各 128 条；客户静态数据库副本上，64 个写入积压时设备列表、设备树和用户信息均正常响应。性能结果为本机验证，仍需 Windows 现场验证。

客户端与服务端统一升级至 1.0.37，使用 GitHub Actions 生成 Windows 标准版和 Win7 版安装包。
